Cara Instalasi

Aplikasi Desktop (Windows)

  1. Klik "Lihat semua file" pada kartu rilis di atas
  2. Di halaman rilis, unduh file .exe pada bagian Assets
  3. Double-click file yang sudah diunduh
  4. Jika muncul peringatan Windows SmartScreen, klik "More info" lalu "Run anyway"
  5. Ikuti wizard instalasi
  6. Klik icon di desktop untuk memulai

Aplikasi Android

  1. Klik "Lihat semua file" pada kartu rilis di atas
  2. Di halaman rilis, unduh file .apk pada bagian Assets
  3. Buka file yang sudah diunduh, lalu izinkan "Instal dari sumber tidak dikenal" jika diminta
  4. Ketuk "Instal" dan tunggu sampai selesai
  5. Pilih mode permainan yang diinginkan
  6. Klik "Play" dan mulai bermain
